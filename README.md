This repository contains simple examples that I applied by developing SQLite relational databases.
It consists from basic SQL keywords, statements, constraints and data types

1. Keywords
- SELECT - retrieves data from database
- FROM - specifies table from which data should be retrieved
- WHERE - filters relevant results

2. Statements
- CREATE TABLE statement - creates a new table
- DROP TABLE - deletes existing table
- INSERT INTO statement - enters new data in a table
- UPDATE statement - modifies existing data in a table
- DELETE statement - removes data from a table

3. Data types
-  INTEGER - whole number
-  FLOAT - decimal number
-  TEXT - string used for text entries

4. SQL constraints
-  PRIMARY KEY - uniquely identifies each row in a table
-  FOREIGN KEY - identifies a row/record in other table
-  TEXT UNIQUE - shows different values in a column
-  TEXT NOT NULL - ensures that columns cannot have a NULL value
